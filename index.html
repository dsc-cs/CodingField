Safe by design: only `+ − * / % ^ ( )` are allowed. Anything else raises an error — no `__import__`, no `eval`, no variable references. See calc.js for the evaluator, calc.py for the Python equivalent (same grammar).

How it works

The web page loads calc.js and calls evaluate(str)
on =. Python's calc.py mirrors the same grammar
via a restricted ast walk — so the answer is identical in both.
CI runs 12 Python tests in pytest test_calc.py plus a
Node smoke test of calc.js before any deploy.
